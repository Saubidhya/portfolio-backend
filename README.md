# Portfolio Backend - COMP229 Assignment 2

## Description
Backend REST API for Portfolio application built with Node.js, Express, and MongoDB.

## Features
- RESTful APIs for Contacts, Projects, Services, and Users
- MongoDB Atlas integration
- CRUD operations
- Error handling and validation

## Technologies Used
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose ODM
- CORS
- Morgan

## Installation
```bash
npm install
npm run dev
